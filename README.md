# 衡策投资系统（BalanceAlpha）

单用户基金 / ETF / LOF 投资管理与策略决策支持系统，面向“记录交易、维护持仓、抓取行情、生成策略建议、回看版本历史”的完整闭环。

## 项目概览

BalanceAlpha 目前是一个基于 Flask 的本地 Web 应用，核心目标是把投资执行过程拆成 6 个清晰模块：

- `仪表盘`：查看账户总览、最近交易、待处理信号
- `产品管理`：维护基金 / ETF / LOF 基础信息，抓取最新价格和历史行情
- `交易记录`：录入买入、卖出等交易
- `持仓管理`：基于交易与行情计算当前持仓、市值、盈亏和权重
- `策略建议`：生成核心账户与战术账户的策略信号，并支持版本历史查看
- `参数配置`：维护策略模板 JSON 参数，模板版本自动递增

## 当前功能

### 1. 双账户策略体系

- `核心配置账户`：面向长期配置、定投、再平衡
- `战术轮动账户`：面向趋势交易、止盈止损、主动风控
- 页面和信号逻辑均按账户类型区分

### 2. 产品管理

- 支持基金、ETF、LOF 等产品录入
- 支持通过基金代码搜索并自动补全信息
- 支持抓取单个产品最新价格
- 支持导入指定天数的历史行情
- 支持筛选产品状态和默认账户类型

### 3. 交易与持仓

- 支持手工录入交易
- 支持手工录入持仓，若产品不存在可自动创建产品
- 持仓页默认自动刷新最新价格
- 自动展示持仓市值、浮盈浮亏、仓位权重
- 提供 AJAX 刷新接口，便于前端无刷新更新

### 4. 策略建议

- 核心账户：基于权重偏离、回撤、趋势、评分生成建议
- 战术账户：基于 MA 趋势、止损、止盈、确认加仓生成建议
- 支持查看单条建议详情和调仓建议占位信息
- 支持 JSON API 获取调仓建议数据

### 5. 策略建议版本化

当前版本已经支持“策略建议按批次生成和回看历史版本”：

- 每次点击“生成信号”都会创建一个新的 `batch_version`
- 策略建议列表默认只显示`当前最新版本`
- 可以按`产品 + 账户`查看历史版本
- 详情页可回看同一产品的过往版本记录
- 旧版本待处理信号在生成新版本后会自动标记为 `expired`

### 6. 参数配置与日志

- 策略模板以 JSON 形式维护
- 每次修改模板参数，模板版本号自动递增
- 参数变更会写入系统日志
- 策略信号生成也会记录日志

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

```bash
python run.py
```

默认访问地址：

```text
http://127.0.0.1:5000
```

### 3. 首次启动会自动完成

- 创建数据库文件 `data/balancealpha.db`
- 创建数据目录和导入目录
- 创建全部表结构
- 自动补齐 `signals` 表中的运行时升级字段
- 初始化 2 个账户
- 初始化 4 个策略模板

## 配置说明

应用会自动读取 `.env`。如果没有该文件，也可以直接使用默认开发配置启动。

可选环境变量示例：

```env
FLASK_ENV=development
SECRET_KEY=your-secret-key
DATABASE_URL=sqlite:///data/balancealpha.db
```

默认配置要点：

- `FLASK_ENV` 默认是 `development`
- 数据库默认是项目内 SQLite 文件
- `SECRET_KEY` 未配置时使用开发默认值

## 推荐使用流程

1. 在`产品管理`中新增产品，或通过基金代码搜索补齐信息
2. 为产品抓取最新价格和历史行情
3. 在`交易记录`中录入买卖交易
4. 到`持仓管理`查看自动计算后的持仓、盈亏和权重
5. 在`参数配置`中检查策略模板参数是否符合你的策略规则
6. 在`策略建议`中生成最新一版信号
7. 如需回溯，进入某个产品的`历史版本`查看不同版本建议

## 信号版本机制

`signals` 表当前包含以下版本化字段：

- `batch_id`：同一次生成批次的唯一标识
- `batch_version`：按生成次数递增的版本号

版本规则：

1. 新生成一次信号，版本号加 1
2. 新版本生成完成后，旧的 `pending` 信号统一标记为 `expired`
3. 策略建议列表仅展示最新版本
4. 历史页按版本倒序展示

说明：

- 应用启动时会自动检查并补齐 `signals.batch_id` 和 `signals.batch_version`
- 对于旧数据库，一般不需要手工迁移；如需单独处理，也可以使用 `scripts/migrate_signals_version.py`

## 项目结构

```text
BalanceAlpha/
├── app/
│   ├── __init__.py              # Flask 应用工厂、自动建表、运行时字段补齐
│   ├── config.py                # 配置项
│   ├── extensions.py            # 扩展初始化
│   ├── models/                  # ORM 模型
│   ├── services/                # 业务逻辑层
│   │   ├── fund_data_fetcher.py # 行情/基金信息抓取
│   │   ├── signal_service.py    # 策略信号与版本逻辑
│   │   ├── position_service.py  # 持仓计算
│   │   └── trade_service.py     # 交易处理
│   ├── views/                   # Flask 路由
│   ├── templates/               # Jinja2 模板
│   ├── static/                  # CSS / JS
│   └── utils/                   # 常量与工具函数
├── data/                        # SQLite 数据文件与导入目录
├── scripts/                     # 初始化、迁移、导数脚本
├── requirements.txt
├── run.py
└── README.md
```

## 已知边界

- 调仓建议详情目前还是结构化占位，尚未实现完整分步买卖金额计算
- 回测模块仍处于预留 / 开发中状态
- 当前默认数据库为 SQLite，更适合单机个人使用
- 行情抓取依赖外部数据源，稳定性受网络和第三方接口影响
